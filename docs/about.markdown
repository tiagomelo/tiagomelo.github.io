I'm a software engineer specializing in [Go](https://go.dev/), distributed systems, and cloud-native infrastructure. I'm also a technical writer — this website is where I share technical articles, tips, and open source work.

I started my career in 2003 with [Delphi](https://pt.wikipedia.org/wiki/Delphi_(software)), moved to [Java](https://en.wikipedia.org/wiki/Java_(programming_language)) in 2004, and became a polyglot in 2007 when I picked up [Ruby](https://en.wikipedia.org/wiki/Ruby_(programming_language)), [Perl](https://en.wikipedia.org/wiki/Perl), and [shell scripting](https://en.wikipedia.org/wiki/Shell_script). I started working with Go in 2017 and it's been my primary language since.

My first experience with cloud was in 2009 with [Google App Engine](https://cloud.google.com/appengine). I started working with [AWS](https://aws.amazon.com/) in 2014. Today, both [AWS](https://aws.amazon.com/) and [GCP](https://cloud.google.com/) are the cloud providers I'm most experienced with.

I'm seasoned with major relational databases like [Oracle](https://en.wikipedia.org/wiki/Oracle_Database), [SQL Server](https://en.wikipedia.org/wiki/Microsoft_SQL_Server), [MySQL](https://en.wikipedia.org/wiki/MySQL), and [Postgres](https://en.wikipedia.org/wiki/PostgreSQL), as well as non-relational ones like [MongoDB](https://en.wikipedia.org/wiki/MongoDB). Big enthusiast of containers: [Docker](https://en.wikipedia.org/wiki/Docker_(software)), [docker-compose](https://en.wikiversity.org/wiki/Docker/Compose), [Kubernetes](https://en.wikipedia.org/wiki/Kubernetes), [Helm](https://wikitech.wikimedia.org/wiki/Helm).

I've built REST APIs, gRPC services, ETL pipelines, desktop applications, and more, across architectural styles like microservices, pub/sub, event-driven, and actor model.

I don't have strong preferences regarding languages, frameworks, or methodologies. I believe in the right tool for each mission.
