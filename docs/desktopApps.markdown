It is listed at [Fyne's official website](https://apps.fyne.io/apps/info.tiagomelo.imageresizer.html).

[MacOSDMGCreator](https://github.com/tiagomelo/macos-dmg-creator): A macOS DMG package builder with a native GUI written using [Fyne](https://fyne.io) and CLI support.

It is listed at [Fyne's official website](https://apps.fyne.io/apps/info.tiagomelo.macosdmgcreator.html).
